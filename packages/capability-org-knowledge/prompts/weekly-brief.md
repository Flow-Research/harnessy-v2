# Prompt: Weekly Brief

Use for a weekly rollup across approved meeting artifacts, context updates, and issue suggestions.

## Instruction

Create a `weekly` brief with `templates/brief.md`. Emphasize themes, decisions, progress, risks, repeated blockers, and next-week priorities. Separate facts from recommendations.

## Output

Return a weekly brief with source ids and a review note for unresolved questions, sensitive items, and recommended follow-up meetings or issues.
