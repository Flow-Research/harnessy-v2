# Prompt: GitHub Issue Suggestions

Use when approved meeting artifacts imply repository work.

## Instruction

Create one or more `templates/github-issue-suggestion.md` drafts. Suggest issues only for concrete, actionable repository work. Include evidence from decisions or action items. Do not call GitHub APIs and do not claim an issue exists.

## Output

Return issue suggestions sorted by confidence. Include a triage note for each suggestion and explain why any candidate was rejected.
