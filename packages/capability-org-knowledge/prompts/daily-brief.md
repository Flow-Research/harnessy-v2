# Prompt: Daily Brief

Use for a daily summary across approved meeting artifacts, wiki/context update proposals, and issue suggestions.

## Instruction

Create a `daily` brief with `templates/brief.md`. Prioritize decisions, due-soon actions, blockers, and review-needed updates. Use only approved or clearly labeled draft sources. Keep raw meeting content out of the brief.

## Output

Return a concise daily brief plus a review note that identifies sensitive items and missing approvals.
